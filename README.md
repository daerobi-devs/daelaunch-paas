# DaeLaunch PaaS // Personal Developer Cloud Platform

Modern Mini-PaaS & Cloud App Engine powered by **Next.js 15, Coolify API, and PostgreSQL (pgvector:pg18)**.

---

### 🚀 Key Features:
- **Zero-Config Deployment**: Deploy any public GitHub repo instantly via Coolify Nixpacks builder.
- **Strict Sandbox & Quotas**: 2 apps max per free user, 512MB RAM container ceiling.
- **Admin God-Mode**: Complete visibility over all tenants, resource usage, and kill-switch capabilities.
- **Secure Integration**: Interacts with Coolify and PostgreSQL via internal Docker network / Tailscale proxy.
